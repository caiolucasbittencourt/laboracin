Site institucional para o laboratório de análises clínicas Laboracin, desenvolvida para ser moderna e totalmente responsiva.

## Funcionalidades

- **Design Responsivo:** Layout adaptável para uma experiência de usuário consistente em desktops, tablets e dispositivos móveis.
- **Animações de Scroll:** Efeitos sutis de revelação de conteúdo conforme o usuário rola a página, utilizando a biblioteca ScrollReveal.js.
- **Seções Dedicadas:** Apresentação clara dos serviços, história do laboratório, informações de contato e mapa de localização integrado.

## Tecnologias

- Next.js
- React
- TypeScript
- Tailwind CSS
- ScrollReveal.js
